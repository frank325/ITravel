# AGENTS.md

## Cursor Cloud specific instructions

### Project Overview

iTravel (爱旅游) is a legacy Android (Java) travel application targeting SDK 26. The repository contains **only the Android client**; the backend (`ITravelWeb`) is external and not included.

### Build Environment

- **JDK 8** is required (`JAVA_HOME=/usr/lib/jvm/java-8-openjdk-amd64`).
- **Android SDK** is at `/opt/android-sdk` with platform `android-26` and build-tools `26.0.0`.
- Environment variables `JAVA_HOME`, `ANDROID_HOME`, and `ANDROID_SDK_ROOT` must be set (configured in `~/.bashrc`).
- `local.properties` with `sdk.dir=/opt/android-sdk` must exist at the project root (not committed — generated by the update script).

### Key Commands

| Task | Command |
|---|---|
| Build debug APK | `./gradlew assembleDebug` |
| Run unit tests | `./gradlew test` |
| Run lint | `./gradlew lint` (will fail with existing lint errors in the codebase; use `lintDebug` for debug-only) |
| Clean | `./gradlew clean` |

### Gotchas

- The root `build.gradle`, `settings.gradle`, and Gradle wrapper files were missing from the original repo and had to be created. They are committed as part of environment setup.
- `app/build.gradle` uses deprecated `compile`/`testCompile`/`androidTestCompile` configurations (should be `implementation`/`testImplementation`/`androidTestImplementation`). These produce deprecation warnings but still work with AGP 3.0.1.
- The `com.zhy:okhttputils:2.6.2` dependency requires the Aliyun jcenter mirror since the original jcenter is shut down.
- Lint reports pre-existing errors in the codebase (`./gradlew lint` exits non-zero). This is expected.
- The app connects to an external backend at a hardcoded private IP (`192.168.8.106:8989`). Without this backend, the app will build and unit tests will pass, but the app cannot function at runtime.
- Android SDK command-line tools require JDK 17+ to run `sdkmanager`, but the Gradle build requires JDK 8. When installing new SDK packages, temporarily use `JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64` for sdkmanager commands.
